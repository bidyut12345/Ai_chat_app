Built-in tools

          

            The app ships five MCP servers of its own: files, shell,
            windows, chrome and edge.
            windows drives the desktop (windows, typing, clicking, screenshots);
            chrome / edge drive a browser in its own profile, so your normal
            browsing profile is never touched. Every chat has its own working folder,
            approval mode and file / shell access — open the
            + menu next to the message box to switch each server on or off for that chat.
            A new chat starts in your home folder with Ask me first, access restricted to that
            folder, and all tool sets on. Switch a server off for all chats in
            MCP servers below.
          

          
          
          

            
          

          

        


        

          
Accounts

            The first account is always allowed.

            servers as you like. Each one is connected at the same time and its tools are namespaced as
            server__tool, then offered to the model when MCP tools is on.
